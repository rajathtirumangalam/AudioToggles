# AudioToggles

AudioToggles is an NVDA add-on that provides quick keyboard shortcuts to toggle system speaker mute and microphone mute directly from NVDA.

## Features

* Toggle speaker mute from anywhere in Windows.
* Toggle microphone mute from anywhere in Windows.
* Spoken mute and unmute announcements.
* Delayed mute activation to ensure announcements are fully spoken before audio is muted.
* Gestures can be customized through NVDA Input Gestures.

## Default Keyboard Shortcuts

| Action                 | Shortcut             |
| ---------------------- | -------------------- |
| Toggle speaker mute    | NVDA+Control+Shift+M |
| Toggle microphone mute | NVDA+Control+Shift+U |

These shortcuts can be changed through:

NVDA Menu → Preferences → Input Gestures → AudioToggles

## Installation

1. Download the latest `.nvda-addon` package from the Releases page.
2. Open the downloaded file.
3. Choose **Install** when NVDA prompts.
4. Restart NVDA if required.

## Notes

* Microphone mute functionality depends on Windows hardware and driver support.
* Some systems may provide additional operating system notifications when mute status changes.
* AudioToggles is designed to provide a simple and accessible way to control audio devices without leaving the keyboard.
