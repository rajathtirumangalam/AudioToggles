Audio Toggles

An NVDA add-on for controlling Windows audio from the keyboard: mute the speaker or microphone, switch playback and recording devices, adjust volume, save device presets, and control individual applications.

Keyboard commands

All defaults can be changed in NVDA's Input Gestures dialog, under the Audio Toggles category.

  • NVDA+Ctrl+Shift+M: toggle speaker mute
  • NVDA+Ctrl+Shift+U: toggle microphone mute
  • NVDA+Ctrl+Shift+O: switch to the next playback device
  • NVDA+Ctrl+Shift+I: switch to the next recording device
  • NVDA+Ctrl+Shift+D: speak the current playback and recording devices with volume and mute state
  • NVDA+Ctrl+Shift+L: open the audio devices list
  • NVDA+Ctrl+Shift+Up Arrow and Down Arrow: speaker volume up and down
  • NVDA+Ctrl+Shift+P: apply the next saved preset
  • NVDA+Ctrl+Shift+A: mute or unmute the application you are using

These commands have no default gesture; assign them in Input Gestures if you want them:

  • microphone volume up and down
  • set the speaker volume to a specific level
  • open the presets manager
  • open the application volumes list
  • open the Audio Toggles settings

Audio devices list

Works like NVDA's Elements List. Choose Playback or Recording, type in the filter box to narrow the list, then press Enter on a device to make it the default. Buttons let you mute or unmute a device, and skip it when cycling.

Application volumes

Lists applications that currently have audio on the default playback device. Mute, unmute, and change the volume of each. NVDA itself is never listed, so you cannot accidentally silence your screen reader.

Presets

A preset stores a playback and a recording device. Save the current pair under a name, apply a preset from the manager, or press the preset shortcut to cycle through them. Devices that are not connected are skipped.

Settings

Open NVDA settings and choose Audio Toggles.

  • Language of spoken messages: follow NVDA, or choose English, Hindi, Bengali, Tamil, Telugu, Marathi, Gujarati, Kannada, Malayalam or Punjabi. Dialog text always follows NVDA's own language.
  • Feedback type: speech, tones, or both.
  • Delay before muting the speaker, so the announcement finishes before NVDA goes silent.
  • Volume step.
  • Which Windows roles (console, multimedia, communications) change when you switch device.
  • Short device names.
  • Device monitoring: announce when devices connect or disconnect, and optionally switch to a newly connected playback device.
  • Devices to skip when cycling.
  • Manage presets.

Notes

  • Mute state is read from Windows, so announcements always match reality, even if you muted from another program.
  • Muting the speaker also silences NVDA. The add-on announces first and mutes after the delay you choose.
  • Per-application control covers applications playing on the default playback device only.
  • The add-on is disabled on secure screens such as sign-in and UAC.
  • Requires NVDA 2023.1 or later.

Translations

Translations live in addon/locale/<language>/LC_MESSAGES/nvda.po. They were drafted without native-speaker review, so corrections are welcome. Edit the .po file and rebuild. translations/AudioToggles.pot is the template for adding a language.

Building

python tools/gen_locale.py   # only when changing translations_data.py
python build.py              # writes dist/AudioToggles-<version>.nvda-addon
python -m unittest discover tests
