# Audio Toggles

Audio Toggles is an NVDA add-on that lets you control system speaker mute, microphone mute, and cycle between available Windows audio output devices using keyboard shortcuts.

## Features

- **Toggle speaker mute:** Quickly mute or unmute your system speakers.
- **Toggle microphone mute:** Quickly mute or unmute your microphone.
- **Cycle audio output devices:** Switch between available Windows audio output devices using a keyboard shortcut.

## Default Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `NVDA+Ctrl+Shift+M` | Toggle speaker mute |
| `NVDA+Ctrl+Shift+U` | Toggle microphone mute |
| `NVDA+Ctrl+Shift+O` | Cycle to the next audio output device |

## Requirements

- Windows operating system
- NVDA screen reader
